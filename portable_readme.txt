Illya's live-translate tools —— 便携版
========================================

【怎么用】
1. 双击 live-translate-gui.exe
2. 选好参数，点「▶ 开始翻译」
   · 抓系统声音：你电脑（或浏览器）里正在放的声音，别静音
   · 抓直播间网址：把直播间链接或房间号填进右边那一格，只抓这一路，
     你可以同时听别的音乐、也可以把网页静音
3. 想看大字幕：点「打开字幕页」（浏览器打开 http://127.0.0.1:8777），
   或者点「弹出字幕浮窗」——无边框、置顶、半透明、能拖动、右下角能缩放

【翻译用什么】（界面「翻译模型」那一行二选一）
· 本地模型 = NLLB-200：离线、不花钱、极快（50~90 ms/句）。够听懂大意，
  但口语、人名、梗会翻错，当正经字幕用不行
· 云端 API = DeepSeek：质量最好（0.5~1 秒/句），需要联网 + 一个 API Key。
  Key 在界面那一格点开填一次就记住了。注意：包里的 gui_settings.json 里
  Key 是空的（怕泄露，没带原机上的那把），到新电脑填一次就行；
  也可以把 Key 单独写进 live-translate-gui\api_key.txt
· 列表里还有「Ollama 本地大模型」：质量接近云端、又能离线，
  但要自己先装 Ollama 并拉好模型（选它时程序会检查并问你要不要下载）

【模型都在包里，解压就能用（不需要联网下载）】
  models\nllb-200-distilled-600M-ct2   本地翻译模型（约 620 MB）
  models\faster-whisper-small          识别模型 small（约 460 MB，默认用它）
· 想要更准的识别：界面「识别模型」选 large-v3 / medium（约 3.1 GB / 1.5 GB），
  会联网下载到 models\ 里；下过一次就不再下（开跑前会弹窗告诉你多大）
· 注意：live-translate-gui\ 和 models\ 这两个文件夹要放在一起，
  程序会从 exe 所在目录往上找 models\（往上 3 层内），别只拷其中一个

【这台电脑需要什么】
· Windows 10/11 64 位
· 摄像头不用、麦克风不用；只读系统正在播放的声音
· 有 NVIDIA 显卡 → 「运行设备」保持 auto，会用 GPU，又快又准
  没有显卡 → 自动退回 CPU，建议「识别模型」选 small
· ffmpeg.exe 已经打包在程序目录里，不需要另外安装

【东西都在哪儿】
  live-translate-gui\      程序：live-translate-gui.exe + _internal\（别删别单移）
                           + ffmpeg.exe + gui_settings.json（你的设置/Key）
  live-translate-gui\logs\ 每场翻译的记录（jsonl）和运行日志
  models\                  AI 模型（本地翻译模型 + 识别模型）

【遇到问题】
· 没字幕出来 → 先确认不是静音（含浏览器单独静音），或换「抓直播间网址」模式
· 字幕一直显示「[翻译失败: HTTPError]」→ API Key 错了或没余额，修 Key 或改回本地模型
· 提示「8777 端口已被占用」→ 有旧实例没退干净，换个端口或先杀旧进程
· 想排查 → 勾上「显示运行日志」，会多一个控制台窗口实时打印
· 直播断了 → 网址模式会自动重连，1.5 秒一次，最多 10 次
